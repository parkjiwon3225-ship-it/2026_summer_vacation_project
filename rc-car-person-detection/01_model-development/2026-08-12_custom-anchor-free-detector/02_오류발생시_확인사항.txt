오류 발생 시 확인 사항
======================

1. ModuleNotFoundError: rc_detector
conda activate rc-person-detector
python -m pip install -e .

2. CUDA available: False
nvidia-smi
python -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.is_available())"
전체 학습을 시작하지 말고 결과를 기록한다.

3. CUDA out of memory
설정 파일의 batch_size를 8에서 4, 다시 2 순서로 낮춘다.
필요하면 gradient_accumulation을 2 또는 4로 높인다.

4. 경로가 Parkj 사용자 폴더를 가리킴
업데이트된 스크립트는 프로젝트 위치를 자동 인식한다.
구버전이면 명령 끝에 --root . 을 붙인다.

5. AMP dtype 오류
losses.py에서 target boxes는 torch.float32를 사용해야 한다.
최종 업데이트 bundle에는 수정되어 있다.

6. 학습이 중단됨
last.pt가 존재하면 resume 명령으로 재개한다.

7. 결과 수집
각 노트북의 results\training\실험이름 폴더 전체를 USB에 복사한다.
checkpoint와 history.csv, warnings.log, device.json을 모두 포함한다.
