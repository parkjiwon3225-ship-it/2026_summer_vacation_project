# 2026-08-18 R25-R31 및 Long-run 성능 탐색

## 목적

기존 320×240 FPN48 모델의 성능 한계를 확인하고, 입력 해상도 증가와 seed 변화가 사람 탐지 성능에 미치는 영향을 비교했다.

주요 비교 대상:

- R25 quality loss weight 증가
- KITTI 추가 데이터 실험
- 320×240 seed 재현성
- 480×360
- 640×480
- 고해상도 학습 후 320×240 fine-tuning

평가는 validation `mAP50:95`를 최우선 기준으로 사용했다.

## 핵심 결론

### 1. 640×480이 현재 가장 강한 설정

`results27 / stage1_640_seed11`이 mAP50:95 **0.288050**으로 현재까지 최고 성능을 기록했다.

동일한 640×480 계열의 다른 seed인 `results26 / stage1_640_seed14`도 **0.277340**을 기록했다.

따라서 640×480의 성능 향상은 단일 seed의 우연한 결과로 보기 어렵다.

현재 accuracy champion:

```text
run: longrun_s5_stage1_640_seed11
input: 640×480
seed: 20260811
best epoch: 52
mAP50:95: 0.2880503189
AP50: 0.579422
AP75: 0.253529
Precision: 0.828927
Recall: 0.381651
F1: 0.522661
2. 320×240은 대략 0.24~0.25 수준
320 계열 결과:
seed11: 0.248615
seed14: 0.252407
seed15: 0.243615
seed에 따라 차이는 있지만 전반적으로 약 0.24~0.25 구간에 형성됐다.
640×480은 이 범위를 분명하게 넘어섰다.
3. 480×360은 기대보다 낮음
480×360 실험:
mAP50:95 = 0.244069
320 최고 결과보다 낮았다.
따라서 단순히 해상도를 조금 증가시키는 것이 항상 성능 개선으로 이어지지는 않았다.
4. 고해상도 → 320 fine-tuning은 실패
640 또는 480으로 학습한 뒤 320으로 fine-tuning한 stage2 모델들의 성능은 크게 감소했다.
640 seed11 → 320: 0.231669
640 seed14 → 320: 0.200851
480 seed11 → 320: 0.201463
현재 구조에서는 고해상도 학습의 이점을 320 입력으로 안정적으로 이전하지 못했다.
따라서 이 방식은 현재 주력 방향에서 제외한다.
5. R25 quality loss 1.5는 개선 없음
R25:
mAP50:95 = 0.215796
best epoch = 18
기존 FPN48 기준보다 낮아 quality loss weight 증가 방향은 제외한다.
6. KITTI 추가 데이터 실험도 개선 없음
Kaggle + KITTI + negative 1000 구성:
mAP50:95 = 0.201347
best epoch = 17
현재 validation 기준에서는 기존 Kaggle 기반 모델보다 성능이 크게 떨어졌다.
따라서 KITTI 추가는 현재 주력 학습 데이터 방향에서 제외한다.
